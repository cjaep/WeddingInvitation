# 모바일 청첩장 — 최재필 ♥ 김나영

2027년 6월 19일 토요일 오후 6시, 양재 엘타워 그레이스홀

## 폴더 구조

```
index.html            # 메인 페이지 (섹션 구성)
css/style.css         # 디자인 (색상 토큰은 :root 에 있음)
js/config.js          # 문구·날짜·계좌·API 주소 설정 ← 주로 여기를 수정
js/main.js            # 동작 (달력, 갤러리, 방명록, 복사 등)
apps-script/Code.gs   # 구글 스프레드시트 저장 백엔드
assets/photos/        # 사진 (아래 참고)
assets/bgm.mp3        # 배경음악 (직접 넣기)
```

## 1. 사진 넣기

`assets/photos/` 폴더를 만들고 아래 이름으로 넣으면 자동으로 연결됩니다.

- `main.jpg` — 커버 사진 (세로 또는 가로 모두 가능, 가로형 권장)
- `01.jpg` ~ `18.jpg` — 갤러리 사진

사진 장수를 바꾸려면 `js/config.js`의 `gallery.count` 값을 수정하세요. 사진이 없으면 자리표시자가 보입니다.

## 2. 배경음악 넣기

`assets/bgm.mp3`로 파일을 넣으면 우측 하단 ♪ 버튼으로 재생됩니다. 저작권 문제가 없는 음원(직접 녹음 또는 무료 음원)을 사용해 주세요. 모바일에서는 자동재생이 막혀 있어서 버튼을 눌러야 재생됩니다.

## 3. 구글 스프레드시트 연결 (참석 여부 · 방명록 저장)

1. 구글 스프레드시트를 새로 만듭니다 (이름 예: "청첩장 응답").
2. 메뉴에서 **확장 프로그램 > Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
4. 우측 상단 **배포 > 새 배포 > 유형: 웹 앱**을 선택합니다.
   - 실행 주체: **나**
   - 액세스 권한: **모든 사용자**
5. 배포하면 나오는 **웹 앱 URL**을 복사합니다.
6. `js/config.js`의 `apiUrl`에 붙여넣습니다.

처음 응답이 들어오면 `RSVP`, `Guestbook` 시트가 자동으로 만들어집니다.

> 코드를 수정한 뒤에는 **배포 > 배포 관리 > 편집(연필) > 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로 유지됩니다.

## 4. 내용 수정

`js/config.js`에서 다음 항목을 확인하고 채워 주세요.

- `groom.phone`, `bride.phone` — 전화 버튼용 번호 (비워두면 버튼이 숨겨집니다)
- `accounts` — 계좌 정보 (현재 `은행명`, `000-000-000000`은 예시입니다)
- `greeting.body` — 인사말 (초안이 들어 있으니 원하는 문구로 바꿔 주세요)
- `wedding.address`, `wedding.tel` — 주소와 전화번호는 방문 전 웨딩홀 공식 번호로 한 번 더 확인하세요

## 5. 배포 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다 (예: `wedding-invitation`, Public).
2. 이 폴더를 저장소에 올립니다.
3. 저장소 **Settings > Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택합니다.
4. 몇 분 뒤 `https://<아이디>.github.io/wedding-invitation/` 주소로 접속할 수 있습니다.

## 확인이 필요한 항목

- 그레이스홀이 양재 엘타워 건물 안에 있는지 (검색으로는 건물 주소만 확인했습니다. 웨딩홀 측에 확인해 주세요).
- 티맵 버튼은 티맵 앱이 설치된 기기에서만 동작합니다.
- 참석 여부 폼에 개인정보 수집 동의 문구가 있으니, 필요하면 `index.html`에서 문구를 수정하세요.
